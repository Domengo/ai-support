# Project Reflection: Customer Support AI Agent

One important design decision in this project was to use **Amazon Bedrock with the Strands Agents SDK** to build an AI-powered customer support agent. This approach allows the agent to interpret customer requests, generate contextual responses, and use tools to perform tasks rather than relying only on static answers. Integrating Amazon Bedrock AgentCore Gateway also provides a way to expose external tools to the agent, making the architecture more modular and easier to extend as new customer support capabilities are introduced.

A major challenge was integrating the agent with the MCP tools exposed through AgentCore Gateway. During testing, I encountered compatibility issues with the Strands `MCPClient` API, including an error caused by calling a `get_tools()` method that was not available in the installed version. This highlighted the importance of checking SDK documentation, understanding the difference between synchronous and asynchronous interfaces, and validating tool discovery before testing the complete agent workflow. Effective exception handling and CloudWatch logging were also important for identifying the source of failures instead of treating an unsuccessful agent response as a successful invocation.

For production deployment, **security, reliability, and observability** would be key considerations. Gateway access should use appropriate AWS authentication and least-privilege permissions, while customer information must be handled carefully to protect privacy. The agent should also validate inputs, handle unavailable tools and model errors gracefully, and avoid presenting unverified information as fact. CloudWatch logs and metrics could help monitor failures, latency, and resource usage. Finally, I would test the agent with realistic customer queries, edge cases, and tool failures before release, and evaluate response quality regularly. These measures would help turn the prototype into a more secure, dependable, and maintainable customer support solution.
